# Інструкція для Засновника (Owner)

## Перші кроки
1. Увійдіть на сайт з своїм логіном/паролем
2. Пройдіть 2FA (якщо ще не налаштовано)
3. Змініть пароль при першому вході

## Створення учасника
1. Перейдіть у **Налаштування → Користувачі**
2. Натисніть "Створити користувача"
3. Заповніть:
   - Логін (латиницею)
   - Відображуване ім'я
   - Роль (member/manager/viewer)
   - Тимчасовий пароль (мінімум 10 символів)
4. Після створення передайте людині:
   - URL сайту
   - Логін та тимчасовий пароль
   - Попередьте що при першому вході потрібно змінити пароль

## Призначення в категорію
1. Перейдіть у **Команда → Матриця відповідальності**
2. Клікніть на ячейку "людина × категорія"
3. Виберіть роль: lead (відповідальний), member (виконавець), backup (запасний)
4. Вкажіть конкретні обов'язки
5. Встановіть навантаження (1-5)

## Створення завдання
1. **Завдання → + Нове**
2. Заповніть:
   - Назва (обов'язково)
   - Опис (Markdown)
   - Тип: основне / термінове / додаткове / регулярне
   - Пріоритет: низький / звичайний / високий / критичний
   - Категорія
   - Виконавці (один або кілька)
   - Строк виконання
3. Режим призначення:
   - **Одному** — звичайне завдання
   - **Спільне** — один статус на всіх, видно прогрес кожного
   - **Кожному окремо** — у кожного свій екземпляр зі своїм строком

## Перевірка завдань
- Завдання зі статусом "На перевірці" потребують вашого затвердження
- Перейдіть у завдання → змініть статус на "Виконано" або поверніть на доопрацювання

## Моніторинг
- **Сервери** — статус онлайн/офлайн, гравці, карта
- **Матриця відповідальності** — хто за що відповідає, навантаження
- **Журнал дій** — хто що робив

## Імперсонація (увійти як інший користувач)
1. Перейдіть у **Команда** → оберіть користувача
2. Натисніть "Увійти як..."
3. Підтвердіть пароль (re-auth)
4. Зверху з'явиться червоний банер
5. Для виходу — кнопка "Вийти" в банері

## Регулярні завдання
1. **Завдання → Шаблони**
2. Створіть шаблон з частотою (щодня/щотижня/щомісяця)
3. Крон автоматично створює завдання за шаблоном

## Безпека
- **Ніколи** не передавайте свій пароль іншим
- **Завжди** використовуйте 2FA
- Перевіряйте **Журнал входів** на підозрілу активність
- При підозрі на компрометацію:
  1. Змініть свій пароль
  2. Натисніть "Викинути з усіх пристроїв" у профілі
  3. Перевірте журнал дій
